# Altara Residences

A full-screen React + TypeScript + Three.js property tour, built with Vite, React Three Fiber, Drei, Zustand, GSAP, Tailwind CSS and Lucide.

## Run locally

Use Node.js 22 or newer:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. On Windows PowerShell with script execution disabled, use `npm.cmd` in place of `npm`.

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to a static host. Build command: `npm run build`; output directory: `dist`. No environment variables, accounts or external services are required.

## Your four panoramas

The opening Window View uses the supplied 14400 × 7200 equirectangular photos. Four direct buttons select **9th Day**, **9th Night**, **14th Day**, or **14th Night** in one click. A single panorama shader blends between cached textures over 1.8 seconds with gentle easing. Rapid selections retarget the current blend without resetting its opacity; the previous image remains visible until the next texture is uploaded. Camera direction and zoom are retained. Reduced-motion users switch immediately. No sunset photograph was provided, so no artificial sunset option is presented.

`public/panoramas/` contains 6144 × 3072 desktop WebP files and 3072 × 1536 mobile WebP files. Originals at the repository root are preserved and are not shipped in the production build. To regenerate, run `node scripts/prepare-assets.mjs`.

## Content and replacement guide

- `src/data/project.ts`: navigation, floor numbers, apartment specifications, amenity descriptions and positions, camera presets and model/panorama paths.
- `src/store/useExperienceStore.ts`: navigation and shared view state.
- `src/three/WindowViewScene.tsx`: inward-facing spheres, panorama loading, texture disposal and animated transitions.
- `src/three/PropertyScenes.tsx`: exterior, amenities and apartment concept scenes.
- `src/three/PropertyCamera.tsx`: one camera animation controller for scene entry, amenity and room focus, zoom and reset.
- `src/hooks/useSceneTransition.ts`: coordinated scene/interface fades that retain the WebGL canvas and reveal loaded scenes only. Rapid navigation cancels the previous transition and settles on the latest selection.
- `src/styles/globals.css`: theme and responsive interface.
- `src/app/App.tsx`: interface, accessible dialogs, view selectors and controls.

### Replace panoramas

Export true 2:1 equirectangular images. Replace `9-day.webp`, `9-night.webp`, `14-day.webp`, and `14-night.webp`, including their `-mobile.webp` counterparts. File names map to floor and time in `panoramaPath`. Preserve the same initial orientation in all panoramas; adjust the sphere Y rotation if the supplied property has a different heading. The directional label “Hill side” is descriptive content, not a georeferenced compass reading.

### Replace the building

Replace `public/models/residence.glb` with your final GLB. The bundled building is an original illustrative architectural model generated by `scripts/prepare-assets.mjs`; it is not an accurate representation of the photographed property. Keep its approximate bounds (11 wide × 22 tall × 8 deep), ground at Y=0, or adjust scale, hotspot positions and camera presets. Drei `useGLTF` loads via GLTFLoader with DRACO support enabled. A compressed replacement can use the default decoder; self-host Draco decoders for offline or strict CSP deployments. The tiny bundled model shares geometry and materials and is not Draco-compressed.

### Replace layouts

Apartment types and availability are sample data. The interactive room volumes are concept layouts, not measured floor plans. Edit the room definitions in `src/data/rooms.ts` or substitute a final GLB; move the corresponding labels with the rooms. Amenity illustrations are interface placeholders; the Three.js scene provides spatial context. Supply final photography and accurate coordinates before marketing this as a real property. Location has been removed from the tour.

### Sound

The optional ambience is a quiet locally synthesized chord; no audio tracking or external media is used. The enquiry button and form have been removed.

## Accessibility and performance

Keyboard-focusable controls, native modal focus trapping, Escape dismissal, accessible control names, status announcements, reduced-motion styles, touch gestures, zoom limits, mobile texture variants, lazy-loaded secondary scenes and rendering suspension while the tab is hidden are included. Keyboard arrows select floors, +/− adjust zoom. WebGL failure displays the selected panorama as a static image with an explanatory message. The tour opens on Window View to prioritise the supplied photography.

## Verification

`npm run build` checks TypeScript and creates production assets. Browser flow checks are in `scripts/verify.mjs` (requires a running local server and Playwright Chromium). They exercise the four image combinations, navigation, apartment changes, dialogs, and a mobile viewport.
